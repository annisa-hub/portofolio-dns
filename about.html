Saya adalah lulusan SMKN 1 Nglegok jurusan Teknik Komputer dan Jaringan (TKJ). Saya memiliki dasar pengetahuan dan pengalaman praktik dalam instalasi dan konfigurasi jaringan komputer, penggunaan perangkat jaringan, serta troubleshooting jaringan. Selain itu, saya memiliki kemampuan dasar dalam pembuatan website menggunakan HTML dan CSS, serta pengalaman dalam pembuatan dan pengelolaan web server berbasis Linux Debian, termasuk konfigurasi DNS server dan monitoring jaringan menggunakan Cacti. Saya tertarik untuk berkarier di bidang IT Support atau jaringan dan terus berusaha mengembangkan kemampuan saya di bidang teknologi informasi.
